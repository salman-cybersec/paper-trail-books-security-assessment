# Scope – Paper Trail Books Security Assessment

## Project Objective
To assess web application security risks relevant to an independent bookstore.

## Selected Practice Platform
PortSwigger Web Security Academy

## Selected Lab
SQL injection vulnerability in WHERE clause allowing retrieval of hidden data

## Reason for Selection
This lab was selected because SQL injection can expose data that should not be publicly accessible. This is relevant to bookstore product categories and inventory.

## In Scope
- The selected PortSwigger lab instance launched by the student.
- The Paper Trail Books application developed locally for this project.

## Out of Scope
- Other users' lab instances.
- Real websites without written permission.
- Unrelated PortSwigger labs and external systems.
- Any activity outside the selected lab exercise.

## Testing Restrictions
All testing will be limited to authorized practice environments and the locally developed application.
