# paper-trail-books-security-assessment
Web Application Security Assessment Lab for Paper Trail Books – Scope, Rules of Engagement, bookstore testing documentation.
# Project Overview
This project focuses on the security assessment of a bookstore web application.

# Objective
To identify and understand common web application security weaknesses in an authorized practice environment.

# Practice Target
PortSwigger Web Security Academy

Selected Lab:
SQL injection vulnerability in WHERE clause allowing retrieval of hidden data

# Scope
- The selected PortSwigger practice lab.
- The Paper Trail Books application developed in this project.

# Out of Scope
- Real websites without permission.
- Other users' lab instances.
- Unrelated systems and services.

# Project Structure
- docs/ – Scope and security testing documentation
- app.py – Bookstore application
- data/ – Sample bookstore data
- static/ – Frontend files

# Setup
Setup instructions will be added with the application.

# Testing
Testing will be performed only on authorized practice targets and the local project.
